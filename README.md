# 🚀 듀얼코어 콕핏 (DualCore Cockpit)

> **수험생 전용 올인원 지능형 생산성 OS & 실전 모의고사 페이서**  
> 단일 `index.html` 파일로 브라우저에서 즉시 구동되는 고성능 수험 관리 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. ⏱️ Exam Pacer (수능 실전 모의고사 파이프라인 타이머)
- **과목별 실전 타임테이블 & 프리셋**:
  - 국어 (08:40 ~ 10:00, 80분)
  - 수학 (10:30 ~ 12:10, 100분)
  - 영어 (13:10 ~ 14:20, 70분)
  - 한국사/탐구 (14:50 ~ 16:37)
- **3대 화면 표시 모드**:
  - **듀얼 모드 (Dual)**: 아날로그 수능 시계 + 디지털 타이머 병렬 표시
  - **아날로그 전용 모드 (Analog Only)**: 실제 시험장 분위기를 완벽하게 재현하는 수능 표준 아날로그 시계판 (실시간 시침/분침 싱크)
  - **디지털 전용 모드 (Digital Only)**: 큰 폰트의 직관적인 분/초 카운트다운 타이머
- **순차 파이프라인 타임어택 & 지연 경고**:
  - 문항 영역별(독서, 문학, 화작/언매 등) 목표 시간 분배 및 실시간 페이스 분석
  - 구간 지연 시 시각적 네온 경고 피드백
- **Web Audio API 수능 타종 합성기**:
  - 외부 오디오 파일 없이 Web Audio 합성 기술로 본령/예비령/10분전 타종 음향 생성
  - 독서실/스터디카페를 위한 **무음 시각 플래시(Visual Pulse) 모드** 지원 (화면 테두리 앰버/레드 펄스)
- **Screen Wake Lock API 지원**:
  - 모바일, 태블릿, PC에서 시험 도중 화면이 꺼지지 않도록 방지
  - 탭 복귀 시 자동 재획득 및 수동 토글 지원
- **실수 방지 안전장치 2종**:
  - **페이지 이탈 방지 (`beforeunload`)**: 실수로 탭 닫기/뒤로가기 방지
  - **단계 되돌리기 (Undo Window)**: 파트 넘기기 실수 시 3초 내 이전 파트 롤백

### 2. 📋 Sprint 플랜 (학습 계획 관리)
- 과목별 학습 목표 및 태스크 체크리스트
- 실시간 달성률 게이지 및 직관적인 상태 관리

### 3. 📊 타임 통계 대시보드
- 파트별 실제 소요 시간 vs 목표 시간 비교 분석
- 영역별 페이스 오버/단축 인사이트 시각화

### 4. 🔄 6자리 PIN 클라우드 동기화 (`server.py`)
- 기기간(PC ↔ 태블릿 ↔ 스마트폰) 6자리 고유 PIN 코드로 학습 데이터 실시간 백업 및 복원
- Python 내장 경량 멀티스레드 REST 서버 (`rooms_data.json`)

## 💻 실행 방법

### 방법 1: 로컬 웹 브라우저 단독 실행
- 별도 설치 없이 `index.html` 파일을 더블 클릭하여 바로 실행할 수 있습니다.
- (브라우저 로컬 스토리지(`localStorage`)에 모든 설정과 기록이 영구 보존됩니다.)

### 방법 2: PIN 실시간 동기화 서버와 함께 실행
```bash
# 동기화 서버 구동 (포트 8000)
python server.py
```
- 브라우저에서 `http://localhost:8000` 접속 시 동일 Wi-Fi 내의 태블릿, 모바일 기기와 6자리 PIN으로 데이터 공유가 가능합니다.
