왜 만들었는가:
분절된 수험 루틴의 통합

수험생들은 공부할 때 스톱워치, 플래너 앱, 오답노트, 인강 타이머를 각각 따로 실행합니다. 앱을 전환할 때마다 집중의 흐름이 끊기고, 기록의 파편화가 발생했습니다.

CORE PHILOSOPHY: "남들이 만든 여러 앱에 수험생이 맞추는 것이 아니라, 수험생이 오직 자습과 실전 감각에만 몰입할 수 있도록 필요한 모든 기능을 단 하나의 앱에서 완벽하게 구동하자."
02 // CORE MODULES

듀얼코어를 완성하는 4대 지능형 서브시스템

ENGINEERING & INTERFACE SPECIFICATIONS
SYS.01 REAL EXAM PIPELINE

실전 모의고사 타이머 (Exam Pacer)

평가원 수능 시험장 규격 수침형 아날로그 시계판 동기화와 디지털 타이머의 듀얼 인터페이스. 독서실 환경을 위한 무음 시각 플래시(Visual Pulse)와 Web Audio API 기반 오실레이터 순수 타종음을 내장했습니다.

SYS.02 ADAPTIVE PACING ENGINE

적응형 주간 Sprint 플래너

계획이 밀렸을 때 자책감 대신 수학적 최적 대안(강제상향/주말이월/가지치기)을 3-Way로 재제시합니다. 목표 잔여량과 일일 소화 한도를 역산하여 "매일 N강 소화 시 완주 예정일"을 실시간 뱃지로 산출합니다.

SYS.03 GRADE & CUTOFF TRACKER

스마트 OMR & 기출 확정 등급컷

역대 수능·모평 확정 등급컷 DB를 내장하여 원점수 직접 입력, 틀린 번호만 콕 찍기, 스마트 OMR의 3-Way 초간편 채점을 지원합니다. 채점 즉시 1등급 컷 기준 갭과 전국 백분위 궤적을 SVG 차트로 분석합니다.

DATA: 2024~2025 CSAT CUTOFFS AUTO EVALUATION
SYS.04 REALTIME PRESENCE NODE

6자리 PIN 동기화 & 실시간 라운지

복잡한 로그인 없이 6자리 PIN으로 PC ↔ 태블릿 ↔ 스마트폰 간 데이터를 즉시 동기화합니다. Firebase Cloud Firestore 하트비트를 통해 "현재 전국에서 함께 자습 중인 수험생 수"를 실시간 집계하고 24시간 응원 전광판을 운영합니다.

SYNC: 6-DIGIT PIN ENCRYPTION FIREBASE FIRESTORE

THE OBSTACLE: 기능 과잉으로 인한 정체성 혼란

초기 개발 중 구현하고 싶은 기능이 계속 늘어나면서 플래너, 타이머, 캘린더가 뒤섞여 "이 앱이 도대체 무엇을 위한 것인가?"라는 정체성 상실의 위기를 맞닥뜨렸습니다.

THE SOLUTION: 본질에 집중한 가지치기 및 통합

초심으로 돌아가 '수험생의 실전 자습'에 꼭 필요한 본질적인 요소만을 남겼습니다. 잡다한 UI를 덜어내고, '실전 모의고사 Pacer'와 '주간 Sprint'를 두 개의 핵심 코어(Dual-Core)로 정의하여 일관된 제품 정체성을 확립했습니다.
